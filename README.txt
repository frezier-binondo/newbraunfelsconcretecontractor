New Braunfels Concrete Contractor Website
=============================

HOW TO VIEW LOCALLY
-------------------
1. Unzip this folder completely.
2. Open the file:  index.html
   - Double-click it, or right-click → Open with → Chrome / Edge / Firefox

All CSS, JS, and internal links now use relative paths, so the site should display correctly when opened from the folder.

If styles still do not load:
- Make sure you opened index.html from inside the "hill-country-concrete" folder (not from inside a nested zip view).
- Or run a simple local server:
    - Python:  python -m http.server 8080
    - Then visit: http://localhost:8080
